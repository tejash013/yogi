2. STEP-BY-STEP DEPLOYMENT INSTRUCTIONS (FREE PLATFORMS)
================================================================================

--------------------------------------------------------------------------------
STEP 1: DATABASE SETUP (MongoDB Atlas - 100% Free Forever)
--------------------------------------------------------------------------------
1. Visit: https://www.mongodb.com/cloud/atlas and create or log into your account.
2. Click "Create" and select the "M0 Free" shared cluster.
   - Choose a cloud provider and region closest to your users.
3. Set up Database User (Security -> Database Access):
   - Click "Add New Database User" (Password auth).
   - Username: restaurantos_admin.
   - Password: Choose a strong password and save it.
   - Database User Privileges: Read and write to any database.
4. Configure Network Access (Security -> Network Access):
   - Click "Add IP Address" -> choose "Allow Access from Anywhere" (0.0.0.0/0).
   - Click "Confirm".
5. Get your Connection String:
   - Go to "Database" -> click "Connect" -> Drivers (Node.js).
   - Copy connection string:
     mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/restaurantos?retryWrites=true&w=majority
   - Replace <username> and <password> with your database user credentials.


--------------------------------------------------------------------------------
STEP 2: GOOGLE OAUTH CLIENT ID (Optional for 1-Click Google Sign-In)
--------------------------------------------------------------------------------
1. Go to: https://console.cloud.google.com/apis/credentials
2. Create a Project (e.g., "RestaurantOS").
3. Configure "OAuth consent screen":
   - User Type: External -> enter App name & Support email -> Save.
4. Go to "Credentials" -> click "+ CREATE CREDENTIALS" -> "OAuth client ID":
   - Application type: Web application
   - Name: RestaurantOS Web
   - Authorized JavaScript origins:
       http://localhost:5173
       https://<your-app>.vercel.app (add after frontend deploy)
5. Click "Create" and copy your Client ID:
   Example: 123456789-abcdef.apps.googleusercontent.com


--------------------------------------------------------------------------------
STEP 3: COMMIT & PUSH YOUR LATEST CODE TO GITHUB
--------------------------------------------------------------------------------
Run in your terminal:
  git add .
  git commit -m "feat: add Google 1-click authentication and deployment config"
  git push origin master


--------------------------------------------------------------------------------
STEP 4: BACKEND DEPLOYMENT (Render.com - Free Web Service)
--------------------------------------------------------------------------------
1. Visit: https://render.com and sign up / log in with GitHub.
2. Click "New +" -> "Web Service".
3. Choose "Build and deploy from a Git repository" and connect:
   https://github.com/tejash013/yogi
4. Configure the Web Service:
   - Name: restaurantos-backend
   - Region: Singapore, Frankfurt, or Oregon
   - Root Directory: backend
   - Runtime: Node
   - Build Command: npm install && npm run build
   - Start Command: npm start
   - Instance Type: Free (512MB RAM, 0.1 CPU)

5. Add Environment Variables in Render:
   -----------------------------------------------------------------------------
   KEY                     VALUE / DESCRIPTION
   -----------------------------------------------------------------------------
   NODE_ENV                production
   PORT                    3000
   MONGODB_URI             mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/restaurantos?retryWrites=true&w=majority
   MONGODB_DATABASE        restaurantos
   ACCESS_TOKEN_SECRET     <Generate 32-byte hex string - see command below>
   REFRESH_TOKEN_SECRET    <Generate another 32-byte hex string>
   FRONTEND_URL            https://restaurantos.vercel.app (placeholder for now)
   GOOGLE_CLIENT_ID        <Your Google Client ID from Step 2>
   -----------------------------------------------------------------------------

   * Quick command to generate random 32-byte hex secrets in terminal:
     node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

6. Click "Create Web Service".
7. Once deployed, copy your assigned backend URL:
   Example: https://restaurantos-backend.onrender.com


--------------------------------------------------------------------------------
STEP 5: FRONTEND DEPLOYMENT (Vercel - Free Global Edge Hosting)
--------------------------------------------------------------------------------
1. Visit: https://vercel.com and log in with GitHub.
2. Click "Add New..." -> "Project".
3. Import your GitHub repository: tejash013/yogi.
4. Configure Project Settings:
   - Framework Preset: Vite
   - Root Directory: ./
   - Build Command: npm run build
   - Output Directory: dist
5. Add Environment Variables:
   -----------------------------------------------------------------------------
   KEY                     VALUE
   -----------------------------------------------------------------------------
   VITE_API_URL            https://restaurantos-backend.onrender.com
   VITE_GOOGLE_CLIENT_ID   <Your Google Client ID from Step 2>
   -----------------------------------------------------------------------------
6. Click "Deploy".
7. Once deployed, copy your live frontend URL (e.g., https://yogi-restaurantos.vercel.app).


--------------------------------------------------------------------------------
STEP 6: LINK FRONTEND DOMAIN IN BACKEND & GOOGLE CONSOLE
--------------------------------------------------------------------------------
1. In Render Dashboard -> "restaurantos-backend" -> "Environment":
   Update: FRONTEND_URL = https://yogi-restaurantos.vercel.app
   Click "Save Changes".
2. In Google Cloud Console -> Credentials -> your OAuth client ID:
   Add your live Vercel URL to "Authorized JavaScript origins":
   https://yogi-restaurantos.vercel.app
   Click "Save".
