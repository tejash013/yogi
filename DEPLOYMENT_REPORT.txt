2. RECOMMENDED DEPLOYMENT (FREE TIER / DECOUPLED CLOUD)
================================================================================

Architecture:
  [Vercel / Netlify (Frontend)]  --->  [Render / Railway (Backend)]  --->  [MongoDB Atlas (Database)]

--------------------------------------------------------------------------------
STEP 1: DATABASE SETUP (MongoDB Atlas)
--------------------------------------------------------------------------------
1. Go to https://www.mongodb.com/cloud/atlas and create/log into your account.
2. Create a Free Shared Cluster (M0).
3. In "Security" -> "Database Access":
   - Add a new database user (e.g., username: restaurantos_user, set strong password).
4. In "Security" -> "Network Access":
   - Click "Add IP Address" -> choose "Allow Access from Anywhere" (0.0.0.0/0).
5. In "Database" -> Click "Connect" -> "Drivers" (Node.js):
   - Copy your connection string:
     mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/restaurantos?retryWrites=true&w=majority

--------------------------------------------------------------------------------
STEP 2: BACKEND DEPLOYMENT (Render.com)
--------------------------------------------------------------------------------
1. Go to https://render.com and click "New +" -> "Web Service".
2. Connect your GitHub repo: https://github.com/tejash013/yogi
3. Configure the service:
   - Name: restaurantos-backend
   - Region: Singapore / Frankfurt / Oregon (closest to your users)
   - Root Directory: backend
   - Runtime: Node
   - Build Command: npm install && npm run build
   - Start Command: npm start
   - Instance Type: Free
4. Add Environment Variables in Render:
   -----------------------------------------------------------------------------
   KEY                     VALUE / DESCRIPTION
   -----------------------------------------------------------------------------
   NODE_ENV                production
   PORT                    3000
   MONGODB_URI             mongodb+srv://<user>:<pass>@cluster0.xxx.mongodb.net/restaurantos?retryWrites=true&w=majority
   MONGODB_DATABASE        restaurantos
   ACCESS_TOKEN_SECRET     <Generated 32-byte hex secret - see command below>
   REFRESH_TOKEN_SECRET    <Generated 32-byte hex secret - see command below>
   FRONTEND_URL            https://your-frontend-app.vercel.app (update after frontend is deployed)
   -----------------------------------------------------------------------------
5. Click "Create Web Service".
   Save your backend URL (e.g., https://restaurantos-backend.onrender.com).

* Tip to generate secure 32-byte hex secrets:
  Run in terminal:
  node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

--------------------------------------------------------------------------------
STEP 3: FRONTEND DEPLOYMENT (Vercel)
--------------------------------------------------------------------------------
1. Go to https://vercel.com and click "Add New..." -> "Project".
2. Import your GitHub repository: yogi.
3. Configure Project Settings:
   - Framework Preset: Vite
   - Root Directory: ./
   - Build Command: npm run build
   - Output Directory: dist
4. Add Environment Variable in Vercel:
   -----------------------------------------------------------------------------
   KEY                     VALUE
   -----------------------------------------------------------------------------
   VITE_API_URL            https://restaurantos-backend.onrender.com (your backend URL)
   -----------------------------------------------------------------------------
5. Click "Deploy".
6. Copy your live frontend URL (e.g., https://yogi-restaurantos.vercel.app) and 
   paste it into Render's backend FRONTEND_URL variable.

3. ALTERNATIVE: SINGLE SERVER / VPS DEPLOYMENT (DOCKER COMPOSE)
================================================================================

Deploy the entire stack (Frontend + Backend + MongoDB) on any Linux VPS 
(AWS EC2, DigitalOcean, Hetzner, Linode):

1. Install Docker & Docker Compose on server:
   sudo apt update && sudo apt install -y docker.io docker-compose git

2. Clone repository:
   git clone https://github.com/tejash013/yogi.git
   cd yogi

3. Create backend configuration:
   nano backend/.env

   Add:
   NODE_ENV=production
   ACCESS_TOKEN_SECRET=your_32_byte_hex_secret_here
   REFRESH_TOKEN_SECRET=your_32_byte_hex_secret_here
   FRONTEND_URL=https://your-domain.com

4. Build and start services:
   docker-compose up -d --build

5. Check service health:
   docker-compose ps
   curl http://localhost:3000/health
   # Response: {"status":"ok","service":"restaurantos-backend"}
