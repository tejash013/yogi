3. DEPLOYMENT OPTION A: DECOUPLED CLOUD (RECOMMENDED)
--------------------------------------------------------------------------------
A. FRONTEND HOSTING (Vercel / Netlify / Cloudflare Pages):
   1. Connect your GitHub repository: https://github.com/tejash013/yogi.git
   2. Build Settings:
      - Framework Preset: Vite
      - Root Directory: ./
      - Build Command: npm run build
      - Output Directory: dist
   3. Environment Variables:
      - VITE_API_URL = https://your-backend-api-domain.com

B. BACKEND HOSTING (Render / Railway / Fly.io / AWS App Runner):
   1. Create Web Service pointing to the same repository.
   2. Service Settings:
      - Root Directory: backend
      - Build Command: npm run build
      - Start Command: npm start
   3. Environment Variables:
      - NODE_ENV = production
      - PORT = 3000
      - MONGODB_URI = mongodb+srv://<user>:<password>@cluster.mongodb.net/restaurantos?retryWrites=true&w=majority
      - MONGODB_DATABASE = restaurantos
      - ACCESS_TOKEN_SECRET = <64-character random hex string>
      - REFRESH_TOKEN_SECRET = <64-character random hex string>
      - FRONTEND_URL = https://your-frontend-domain.vercel.app

C. DATABASE (MongoDB Atlas):
   1. Create a free or dedicated cluster on https://www.mongodb.com/atlas
   2. Under Network Access, allow access from anywhere (0.0.0.0/0) or backend IP.
   3. Under Database Access, create a database user and password.
   4. Copy the connection URI into MONGODB_URI.


4. DEPLOYMENT OPTION B: SINGLE SERVER / VPS (DOCKER COMPOSE)
--------------------------------------------------------------------------------
Deploy the full stack onto any Ubuntu/Debian VPS (AWS EC2, DigitalOcean, Hetzner):

Step 1: Install Docker & Docker Compose on your server:
   sudo apt update && sudo apt install -y docker.io docker-compose

Step 2: Clone repository:
   git clone https://github.com/tejash013/yogi.git
   cd yogi

Step 3: Create backend environment configuration:
   nano backend/.env
   
   Add the following:
   NODE_ENV=production
   ACCESS_TOKEN_SECRET=your_generated_access_token_secret_here
   REFRESH_TOKEN_SECRET=your_generated_refresh_token_secret_here
   FRONTEND_URL=https://your-domain.com

Step 4: Launch all services:
   docker-compose up -d --build

Step 5: Verify running containers:
   docker-compose ps
   curl http://localhost:3000/health
