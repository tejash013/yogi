2. STEP-BY-STEP DEPLOYMENT INSTRUCTIONS (FREE PLATFORMS)
================================================================================

--------------------------------------------------------------------------------
STEP 1: DATABASE SETUP (MongoDB Atlas - 100% Free Forever)
--------------------------------------------------------------------------------
1. Visit: https://www.mongodb.com/cloud/atlas and create or log into your account.
2. Click "Create" and select the "M0 Free" shared cluster.
   - Choose a cloud provider and region closest to your users (e.g. AWS / Singapore or Frankfurt).
   - Cluster Name: Cluster0 (default).
3. Set up Database User (Security -> Database Access):
   - Click "Add New Database User".
   - Authentication Method: Password.
   - Username: restaurantos_admin (or your preferred username).
   - Password: Choose or generate a strong password (save this password!).
   - Database User Privileges: Read and write to any database.
   - Click "Add User".
4. Configure Network Access (Security -> Network Access):
   - Click "Add IP Address".
   - Click "Allow Access from Anywhere" (sets IP to 0.0.0.0/0).
   - Reason: Cloud providers like Render use dynamic IP addresses.
   - Click "Confirm".
5. Get your Connection String:
   - Go to "Database" -> click "Connect" on your cluster.
   - Select "Drivers" -> Node.js.
   - Copy the connection string format:
     mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/restaurantos?retryWrites=true&w=majority
   - Replace <username> and <password> with your actual database user credentials.


--------------------------------------------------------------------------------
STEP 2: COMMIT & PUSH YOUR LATEST CODE TO GITHUB
--------------------------------------------------------------------------------
Run the following commands in your terminal to ensure your repository has all
the deployment configuration files:

  git add .
  git commit -m "chore: prepare configuration for cloud deployment"
  git push origin master


--------------------------------------------------------------------------------
STEP 3: BACKEND DEPLOYMENT (Render.com - Free Web Service)
--------------------------------------------------------------------------------
1. Visit: https://render.com and sign up / log in with your GitHub account.
2. In your dashboard, click "New +" -> "Web Service".
3. Choose "Build and deploy from a Git repository" and connect:
   https://github.com/tejash013/yogi
4. Configure the Web Service:
   - Name: restaurantos-backend
   - Region: Singapore, Frankfurt, or Oregon
   - Root Directory: backend
   - Runtime: Node
   - Build Command: npm install && npm run build
   - Start Command: npm start
   - Instance Type: Free (512MB RAM, 0.1 CPU)

5. Add Environment Variables in Render:
   -----------------------------------------------------------------------------
   KEY                     VALUE / DESCRIPTION
   -----------------------------------------------------------------------------
   NODE_ENV                production
   PORT                    3000
   MONGODB_URI             mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/restaurantos?retryWrites=true&w=majority
   MONGODB_DATABASE        restaurantos
   ACCESS_TOKEN_SECRET     <Generate 32-byte hex string - see command below>
   REFRESH_TOKEN_SECRET    <Generate another 32-byte hex string>
   FRONTEND_URL            https://restaurantos.vercel.app (placeholder for now)
   -----------------------------------------------------------------------------

   * Quick command to generate random 32-byte hex secrets in terminal:
     node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

6. Click "Create Web Service".
7. Render will build and deploy your backend.
8. Once finished, copy your assigned backend URL:
   Example: https://restaurantos-backend.onrender.com


--------------------------------------------------------------------------------
STEP 4: FRONTEND DEPLOYMENT (Vercel - Free Global Edge Hosting)
--------------------------------------------------------------------------------
1. Visit: https://vercel.com and log in with GitHub.
2. Click "Add New..." -> "Project".
3. Import your GitHub repository: tejash013/yogi.
4. Configure Project Settings:
   - Framework Preset: Vite
   - Root Directory: ./
   - Build Command: npm run build
   - Output Directory: dist
5. Add Environment Variable:
   -----------------------------------------------------------------------------
   KEY                     VALUE
   -----------------------------------------------------------------------------
   VITE_API_URL            https://restaurantos-backend.onrender.com (your Render URL)
   -----------------------------------------------------------------------------
6. Click "Deploy".
7. Within 1-2 minutes, your frontend will be live!
8. Copy your live frontend URL (e.g., https://yogi-restaurantos.vercel.app).


--------------------------------------------------------------------------------
STEP 5: LINK FRONTEND DOMAIN IN BACKEND CORS
--------------------------------------------------------------------------------
1. Open your Render dashboard -> click on "restaurantos-backend" -> "Environment".
2. Find the FRONTEND_URL variable.
3. Update its value to your actual live Vercel URL:
   FRONTEND_URL = https://yogi-restaurantos.vercel.app
4. Click "Save Changes".
5. Render will automatically redeploy the backend with updated CORS permissions.

4. IMPORTANT NOTES ON FREE CLOUD TIERS
================================================================================
- Render Free Tier Spin-Down:
  Free web services on Render sleep after 15 minutes of inactivity. The first
  request after sleeping takes ~45-50 seconds to wake up (cold start).
  After waking up, it operates normally.

  * Tip to prevent sleep:
    You can use a free monitoring service like https://cron-job.org or
    https://uptimerobot.com to send an HTTP GET ping to:
    https://restaurantos-backend.onrender.com/health
    every 10 minutes. This will keep your backend awake 24/7 at no cost.
